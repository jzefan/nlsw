# 考勤申请与审批流程

日期：2026-10-01。本文讲清「请假 / 加班 / 出差」三类申请从提交到审完的流程，
以及详情页的时间线展示与附件规则。面向使用系统的人（员工、审批人、考勤管理员）。

相关代码：
- 后端 `controllers/api/attendance.js`（提交 / 审批 / 撤回 / 列表 / 附件读取）
- 模型 `models/AttendanceRequest.js`（申请单 + `approvals` 审批链）
- 页面 `front_end/src/pages/attendance/components/RequestList.vue`（我的申请 / 待我审批 / 审核记录共用）
  + `RequestTimeline.vue`（详情时间线） + `AttachmentPreviewDialog.vue`（附件预览）

## 1. 三个入口

| 入口 | 地址 | 看到什么 |
| --- | --- | --- |
| 我的申请 | `/attendance/requests` | 自己提交的（可按类型筛） |
| 待我审批 | `/attendance/approvals` | 当前轮到本人审的（只看 `pending`） |
| 审核记录 | `/attendance/approval-history` | 本人审过的全部记录（**刻意不分类型**） |

三个入口共用同一套列表与详情；「详情」按钮展开的那块就是时间线。

## 2. 审批链怎么生成

| 申请人 | 审批链 |
| --- | --- |
| 普通员工 | 直属经理 →（超过阈值才加）总经理 |
| 本人就是经理 | 总经理 |
| 总经理本人 | 代理审批人（主账号在**员工资料**里指定） |

- 触发总经理终审的阈值默认 **3 个工作日**（`generalManagerThresholdDays`，按工作时段折算成时长）；
  请假超过阈值时提示「请假超过 3 个工作日需要总经理终审」。
- 缺直属经理、缺总经理、缺代理审批人时**提交会被拦下并给可操作提示**，不会生成半截审批链。
- 申请人不能审自己；经理本人申请会跳过自己那一级。

## 3. 详情时间线显示什么

从上到下依次是：

1. **提交申请** —— 申请人 + 提交时间
2. **每一级审批** —— 角色（直属经理 / 总经理 / 代理审批人）+ 状态
3. 被撤回的申请末尾再加一个 **已撤回** 节点

每一级的「状态」按这四种显示：

| 状态 | 什么情况 | 显示 |
| --- | --- | --- |
| 等待中 | 申请还在流转，且轮到这一级 | **等待 \<审批人姓名\> 审批**；**轮到本人时写「等待您的审批」**（蓝色强调，空心圆点） |
| 已通过 | 这一级审过了 | 审批人姓名 + 时间 + 「意见：…」 |
| 已驳回 | 这一级驳回了 | 同上，结论用红色 |
| 未进行 | 申请已结束（通过 / 驳回 / 撤回），后面的层级没走到 | 灰字「未进行」 |

**审批人姓名由后端在返回列表时补上**（审批链本身只存 `approverId`，见
`approverNameMap()`；由于 `approvals` 是 mongoose 子文档、schema 里没有姓名字段，
必须在序列化时注入，直接给子文档赋值会被 strict 模式静默丢掉）。

## 3.1 时长与人员信息怎么显示

- 列表与详情里的「时长」按类型给不同口径：

  | 类型 | 显示 | 规则 |
  | --- | --- | --- |
  | 请假 | **天数** | 时长 ÷ 每日工作分钟（8 小时工作日 → 8 小时 = 1 天；下午半天 5 小时 = 0.63 天） |
  | 出差 | **天数** | 起止日期含首尾的日历天数（当天往返 = 1 天，跨 3 个日期 = 3 天） |
  | 加班 | **时长** | 小时 |

- 详情头部只显示**申请人所在部门**；**不显示工号与职务**（2026-10-01 按使用方要求去掉）。
- 申请人姓名、部门之外的其它身份信息（工号、职务）在员工资料里维护，不在申请详情里重复。

## 4. 附件

- 每个申请最多 5 个、单个不超过 10MB；允许图片、PDF、Word、Excel。
- **能直接看的**：图片（jpeg / png / gif / webp）与 PDF —— 点附件名打开预览弹窗（图片用 `<img>`、PDF 用 `<iframe>`），
  弹窗里还能「下载」。
- **只能下载的**：Word / Excel —— 点附件名直接下载，文件名前是下载图标，悬浮提示「下载后查看」。
- 预览用的是**本地 blob 地址**（`URL.createObjectURL`）：附件接口需要登录态，把接口地址直接丢给
  `<img>` / `<iframe>` 在跨端口下拿不到 cookie，所以先取回二进制再本地渲染；关窗时释放。

### 谁能读附件

申请人本人、主账号、考勤管理员、总经理，以及**审批链上出现过的人**（包括已审过的）。
其他人拿到地址也会被拒（403）。

## 5. 待办提示：审批页那一行的待办链接

在「待我审批 / 审核记录」**同一行最右**按类型列出当前有待审批的入口，如 `待办 请假 2 · 用章 3`，
**每一项都可点**，点一下直达那个审批页（用章审批 → `/seal/requests?view=inbox`）。没有任何待办时整块不渲染。

- **只在审批视图出现**：「我的申请」那一页没有这行页签，也就不会有待办链接。
- **侧栏菜单刻意不放角标**（2026-10-01 按使用方反馈撤掉，原先试过数字角标）：想知道有没有待办，
  进审批页看这一行，或看顶栏通知。
- **口径**：只统计**轮到我审**的（考勤 = `currentApproverId` + `status: pending`；用章非全公司视角同理），
  与各自列表页的收件箱完全一致——链接上的数字点进去一定对得上。
- **跨模块**：用章审批的待办也会出现在考勤页面的提示里（反之亦然），避免「在这个模块里看不到、就忘了审」。
- **刷新时机**：进页面拉一次 + 60 秒轮询；切页面补拉一次；**审完一条立刻刷新**，不用等轮询。
- **权限**：只有能审的人才会请求计数（没有审批权的人不轮询）。
- 计数接口失败时**保留上一次的数字**（不闪、不清零），也不弹错误提示。

## 6. 边界与约定

- 撤回只能在 `pending` 阶段由申请人操作；撤回后审批链上没走到的层级显示「未进行」。
- 申请时间必须精确到整点（三类申请都一样）。
- 加班必须在提交时选**补偿方式**（调休 / 加班费 / 无补偿，默认无补偿）。
- 请假时长按工作日历逐日分摊（`leaveAllocations`），月台账与工资口径都读这份分摊结果；
  没分摊的历史单据在台账里显示「请假分配待核对」。
